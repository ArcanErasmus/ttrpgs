## Combat Options
- Blessings (DC 14 if relevant)
    - **Daily**; 7/day: OOOOO Ox
    - `Healing`: Swift action, Empower (50% more numerical effects) cure spell as being cast
    - `Protection`: Standard action, +1 sacred to AC and saves for self 1 min
- Sacred Weapon +1
    - **Daily**; 4 rds/day: OOOxx
    - Swift action enhance one wpn with *+1*
    - If already +1, can instead give *defending*, *flaming*, *frost*, *ghost touch*, *keen*, *shock*
    - First use locks in blessing configuration for rest of day: ***flaming***
- Fervor (DC 14 if relevant)
    - **Daily**; 4/day: xxxx
    - Positive energy (heal living/harm undead no save) 2d6
        - Standard on others, swift on self
    - Swift action, fast cast (1 rd casting or less) prepared spell
        - Only targets self, doesn't provoke, ignore somatic components, need no free hand
    - Standard action, 2 points, 30-ft radius burst heal/harm (pick) (save for half)
- Shikigami Style
    - Swift action to enter, improvised wpns deal dmg as if 2 sizes larger
    - Can take -2 to hit to treat an improvised weapon as having a quality until start of turn:
        - Blocking, brace, disarm, distracting, nonlethal, performance, trip
        - If fragile quality or broken condition, can treat as if jagged quality
- TWF
    - Extra attack with off-hand weapon whenever full-attack action
    - All attacks during this action at -2 (-4 if off-hand not light)
